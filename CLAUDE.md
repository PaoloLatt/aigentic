# AgentForge Website

## Progetto
Sito web agenzia AI agents. Target: PMI italiane/europee. Lingua contenuti: italiano.
Obiettivo: generazione lead qualificati.

## Design
Dark theme. Font: DM Sans + JetBrains Mono. Mobile-first.
Colori: vedi tailwind.config.ts per la palette completa.
Animazioni: Framer Motion fade-in on scroll. Hover scale+shadow sulle card.

## Tono
Diretto, concreto, zero buzzword. "Facciamo X per ottenere Y."

## Regole codice
- React Server Components di default, "use client" solo quando necessario
- Componenti: PascalCase. File: kebab-case.
- Validazione form client + server
- Responsive: breakpoint a 768px
